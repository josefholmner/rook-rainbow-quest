# Production assets

## Version 0.8.3 launcher and game icon

`assets/rook-rainbow-quest.ico` and `assets/rook-rainbow-quest-icon.png` are original procedural artwork generated by `scripts/make-icon.ps1`, matching the game's smiling cream rook. The ICO contains 16, 32, 48, 64, 128 and 256px images. The PNG is a 256px preview. `assets/icon-{16,32,64}.rgba` contain the same artwork for the native window/taskbar. Windows resource compilation embeds the ICO in both executables. No generated image service or extra player dependency is needed for these code-native assets.

## Version 0.8.2 world paintings

Generated on 25 October 2026 with the built-in imagegen tool, independently for this project:

- `assets/castle-v082.png`: 1586×992. Checkmate Castle's sunny peach/ivory courtyard, rose blossoms, aqua water, coral turrets and rook topiary. Generation output: `exec-17b3957a-f27b-47da-8bec-50dd0965778d.png`.
- `assets/royal-v082.png`: 1586×992. Royal Chess Kingdom's lavender/blue terrace, golden pavilion, floating palace, wisteria and rainbow waterfalls above the clouds. Generation output: `exec-01bf533c-1131-401b-b6f7-15daa4de4420.png`.

Both generation prompts requested a happy, polished hand-painted storybook landscape for children aged 6–7, landscape 16:10, colorful soft contours, detailed edges and a quiet middle for separate UI/board overlays. Both prohibited text, UI, borders, logos, people and chessboards. The courtyard prompt specified peach/rose/ivory/aqua; the royal prompt specified periwinkle/lavender/sky-blue/gold, clearly distinct from meadow, courtyard and space. The prompts requested approximately 1920×1200; the actual returned paintings are 1586×992 and are preserved at that resolution.

All three world textures are embedded, decoded and uploaded once before the first interactive frame, with linear filtering. World maps and levels select the appropriate cached texture by world. A light veil preserves board/text legibility. No runtime downloads, new dependencies, per-frame image decoding or 4K assets were added. World 1's meadow, the main menu and the Adventure Galaxy painting retain their existing artwork.

`assets/meadow.png`: original background generated using the built-in image-generation tool, 23 October 2026, retained as design source. `assets/meadow-v2.png` is the refreshed production background, embedded in the native executable. No runtime image-generation service or API key is used.

Prompt: Original 2D storybook game background for a happy native desktop chess adventure for children aged 6-7. Landscape 16:10 composition. Lush sunny mint-green meadow, sky blue upper third with fluffy white clouds and a small smiling golden sun in upper right. Gentle distant lavender mountains, green rounded hills, small coral-roof fairytale castle very far away upper right around 78 percent across 35 percent down. A wide sandy golden winding path beginning at lower left around 30 percent across 78 percent down, winding past center around 55 percent across 55 percent down then toward castle upper right. Tiny flowers and bushes around edges, two trees framing far left and right corners. Wide open uncluttered middle for UI overlay. Painterly polished tactile children's game art, vivid but calm colors, warm cream, peach coral lavender accents, soft beautiful lighting. Absolutely NO text, lettering, numbers, chess pieces, characters, UI, buttons, panels, flags, level nodes, logos or watermark. Whole image is a seamless illustrated landscape usable behind separately rendered interactive interface. High quality engaging inviting storybook art.

All five chess pieces (rook, bishop, knight, pawn and queen) and their level icons are drawn from primitive shapes in Rust. Cream and purple palettes distinguish teams, with piece silhouettes shared between the board and map. The walking rook mascot remains procedural. Clouds and particle stars are procedural. Four original chime/click sequences are synthesized to PCM WAV in memory at startup. Controls, text and all game state are rendered independently from the background.

`assets/Nunito.ttf`: upstream variable font from https://github.com/google/fonts/tree/main/ofl/nunito. `assets/Nunito-Bold.ttf` is a static weight-700 instance generated with FontTools 4.58.5 for readable game text. SIL Open Font License 1.1, included as `assets/Nunito-LICENSE.txt`. FontTools is a build-session asset preparation tool only; the game and repository setup do not require Python or FontTools.

Refresh prompt (built-in image tool, with original background as reference): Create a higher-resolution production version of this original children's game meadow background. Render at 3840 x 2400 pixels if supported, landscape 16:10, exceptionally crisp detailed clean painterly storybook art suitable for a fullscreen 4K desktop game. Preserve the existing composition, sunny blue sky, fluffy white clouds, smiling golden sun, lavender mountains, rounded green hills, distant coral-roof castle at upper right, sandy winding path, trees at far edges and meadow flowers. Keep the central meadow spacious for game overlays. Improve definition of leaves, flowers, castle and landscape edges without oversharpening. No text, labels, numbers, characters, chess pieces, buttons or UI. This is a full replacement background asset only.

The image tool returned 1586×992 pixels for both backgrounds; the refreshed painting is not claimed to be native 4K artwork. The fullscreen improvement comes from removing the fixed-size game framebuffer, using physical display pixels and 4× MSAA, increasing circle tessellation and rasterizing fonts at the actual display scale. The background uses linear filtering independently from the crisp native game elements.

## Version 0.6

The world selector uses `assets/universe-v06.png` (1586×992), an original built-in imagegen painting. The exact prompt and workflow are in `UNIVERSE-ART.md`. Chess pieces and the mascot still originate in Rust shapes; they are now baked once at 3× logical size into antialiased transparent textures and reused during animation. UI text renders independently at native display resolution.


## Version 0.7 king and shared atlas

The king is original procedural artwork, with a gold cross distinct from the queen crown. The piece/mascot cache now uses one 1536×1920 texture for twelve piece variants and the mascot. World 2 icons pair each level’s lead piece with a purple king; its world island shows a king between rook and queen. No additional generated art or runtime downloads are needed. Native text uses a shared atlas with high-precision UVs to keep settings sharp and reduce texture switches.
