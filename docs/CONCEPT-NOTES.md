## Generation prompt

Use case: ui-mockup. Create a polished two-panel concept sheet for a native Windows desktop chess adventure game for children aged 6–7. Wide image, two equally sized 16:10 game screens side by side, each entirely visible with no cropping. Label above left "WORLD MAP" and above right "LEVEL 01". Original colorful happy storybook game art, chunky rounded UI, crisp readable dark typography, soft tactile pieces, sunny sky, mint hills, cream panels, coral lavender golden yellow accents. No browser chrome or website layout. Left screen title "Little Chess Adventure", bright meadow world map with winding sandy path, flowers, waving flags, drifting fluffy clouds, an adorable recognizable rook character beside an inviting first level stop with numeral 1. Two small distant future stops with a simple lock silhouette. Prominent rounded "Play" button, small sound and settings icon buttons. Right screen title "Rook's Rainbow Trail", instruction "Capture all 3 pawns!", large square chessboard EXACTLY FOUR columns and FOUR rows, alternating warm cream and soft mint squares. Exact board pieces: white smiling ROOK at bottom-left a1; lavender PAWNS at b1 (bottom row second column), d1 (bottom row fourth column), d4 (top row fourth column); all other squares empty. A golden selection ring around rook and subtle straight move dots to illustrate movement. Three small outlined star progress slots. Four rounded controls below board labeled "Hint", "Undo", "Try again", "Map". Small sound icon. Layout is calm, spacious, charming, exceptionally readable, feels like a real game with high quality original illustration. No extra pieces, no extra board squares, no combat, no screenshots from existing games. Static concept only; no claim of working gameplay.
